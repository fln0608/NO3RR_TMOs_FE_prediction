# NO3RR_TMOs_FE_Prediction

[](https://github.com/fln0608/NO3RR_TMOs_FE_prediction/blob/main/README.md#no3rr_tmos_fe_prediction)

Machine learning model for predicting the performance of transition metal oxides (TMOs) catalyst in electrocatalytic nitrate reduction reaction (eNO3-RR), where the performance refers to the Faraday efficiency of ammonia (FE).
